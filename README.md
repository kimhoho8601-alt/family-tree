# 가계도 스튜디오

사례관리자가 최소한의 가족 정보를 입력하고, 자동 생성된 가계도를 직접 편집한 뒤 PNG 이미지로 저장할 수 있는 정적 웹앱입니다.

## 주요 기능

- 가족 구성원 최소 정보 입력 및 수정
- 남성·여성·대상자·사망 표준 기호 표시
- 혼인, 별거, 이혼, 부모–자녀, 친밀, 소원, 갈등 관계선
- 드래그 방식의 자유 배치 및 확대·축소
- 브라우저 로컬 저장 및 고해상도 PNG 다운로드
- 별도 서버나 개인정보 전송 없는 클라이언트 전용 구조

## 실행

의존성이나 빌드 과정이 없습니다. `index.html`을 열거나 아래처럼 로컬 서버로 실행하세요.

```bash
python3 -m http.server 4173
```

GitHub Pages에서는 저장소의 루트를 배포 대상으로 선택하면 됩니다.

## 기준

첨부된 「사례관리 가계도 작성 표준안 v1.0」의 3세대 원칙, 정보 최소화, 사실 우선, 표준 기호와 관계 표시를 반영했습니다. 사업별 법정서식이나 전산 입력기준이 있는 경우 해당 기준을 우선합니다.
